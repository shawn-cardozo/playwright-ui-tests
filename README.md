# 🎭 Playwright UI Tests

A clean and simple UI automation suite using **Microsoft Playwright** with TypeScript.  
This project tests basic flows on `saucedemo.com` using a Page Object Model structure and CI via GitHub Actions.

---

## 🚀 Features
- UI automation with Playwright
- Page Object Model (POM)
- Smoke, regression, and E2E test suites
- Cross-browser testing
- Automatic HTML test reports
- GitHub Actions CI pipeline
